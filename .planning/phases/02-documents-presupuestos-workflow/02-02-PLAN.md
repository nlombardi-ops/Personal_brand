`documentsForLoop(documents, loopId)`:
  - Returns only documents whose `linked_loop_ids` contains `loopId`.
  - Excludes any document with an archived status even when it is linked.
  - Returns an empty array for a loop with no links, and for an empty input.
  - Orders the result by `uploaded_at` descending; two documents sharing an `uploaded_at` keep
    input order (the comparator is a plain string compare and V8's sort is stable).

`attachLoopId(ids, loopId)`:
  - Appends when absent.
  - Returns an array equal to the input when the id is already present — no duplicate, and the
    order of the existing entries is preserved.
  - Never mutates the input array.

`detachLoopId(ids, loopId)`:
  - Removes the id when present.
  - Returns an array equal to the input when the id is absent.
  - Removing the only entry returns an empty array — an orphan, which is a valid state.
  - Never mutates the input array.

Also assert that `validateDocumentInput({ linked_loop_ids: ["a", "a"] }, { create: false })`
returns a Spanish message and that a 51-element array does too — the duplicate and length caps
Slice 1 declared are what make `attachLoopId`'s de-duplication load-bearing rather than cosmetic.

**`lib/community/document-defaults.ts`** — add three pure helpers with the `urgency.ts`
import-discipline header comment (only the `Document` type may be imported for them; no
framework, no filesystem, no React):

`documentsForLoop(documents: Document[], loopId: string): Document[]` — filter to non-archived
documents whose `linked_loop_ids` includes `loopId`, then sort by `uploaded_at` descending with a
plain string comparator. This is the ONLY place the loop→documents resolution is expressed; the
panel list and the board count chip both call it so they can never disagree.

occurrence of `loopId` removed.

is expressed once instead of being re-derived at each of the four call sites (attach from loop,
detach from loop, assign from document, unassign from document).

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client-supplied `linked_loop_ids` array → stored `Document` | The browser proposes the ENTIRE new link array on every attach and detach. |
| stored document metadata → detail panel DOM | Titles, original filenames and loop titles are free text that may quote neighbour names, rendered in a new surface. |
| document library → loop context | The picker enumerates every non-archived document to a caller who is already authenticated — no cross-tenant boundary exists in this single-user app, but archived records must still not leak. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
