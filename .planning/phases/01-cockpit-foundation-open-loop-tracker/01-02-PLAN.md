`blocked` (D-07 resolution: it flows through the same date logic).

zero-padded year-month-day, a plain string comparison is already chronological, and a stable
sort preserves input order for equal dates. Sort waiting the same way. Sort noDate by
`updated_at` descending (D-06). Parse the due string into a local-midnight Date via an
explicit year/month/day split rather than passing the string to the Date constructor, so it
pairs with a `now` in the same runtime timezone.
