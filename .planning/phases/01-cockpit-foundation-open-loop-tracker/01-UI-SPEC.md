# Phase 1 — UI Design Contract

> Visual and interaction contract for the standalone **Community President** cockpit
> (`/community-president`). Generated by gsd-ui-researcher, verified by gsd-ui-checker.
> Autonomous mode: every value is derived from CONTEXT.md locked decisions (D-01..D-18),
> DESIGN.md tokens, `app/globals.css`, and existing codebase conventions. Values not fixed
> by those sources are marked `(default — assumption)` with rationale.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none |
| Preset | not applicable |
| Component library | none — inline Tailwind CSS v4 utility classes (repo convention per CONVENTIONS.md; no `components.json`, no `tailwind.config.js`) |
| Icon library | `lucide-react` (^0.500, already installed; 16px / `h-4 w-4` default) |
| Font | Geist Sans via `--font-geist-sans` (already wired in `app/layout.tsx`). Geist Mono (`--font-mono`) for the count-strip numerals and relative-date pills only (`tabular-nums`). |
| Animation | `framer-motion` ^12 via the shared `FadeUp` wrapper for board mount; slide-over uses its own transform transition. Respect `prefers-reduced-motion`. |

**Visual-system boundary:** this surface uses the DESIGN.md **portfolio `neutral-*` scale on `#fafafa`** — NOT the finance dashboard's `stone-*` palette. CONTEXT.md "Deferred Ideas" and PROJECT.md explicitly warn against inheriting the dashboard's half-done light-theme migration and its zero mobile support. Keep the three visual systems (portfolio / dashboard / community-president) distinct; community-president tracks the portfolio tokens.

---

## Spacing Scale

8-point scale. All padding, margin, and gap values come from this set:

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gaps, chip inner padding (`px-2 py-0.5` pattern from DESIGN.md tag chip) |
| sm | 8px | Gap between cards in a column, quick-action button gaps |
| md | 16px | Card padding (`p-4`), column inner padding, gap between columns (`gap-4`) |
| lg | 24px | Board outer padding on desktop, slide-over body padding |
| xl | 32px | Page header bottom margin, gap between count strip and board |
| 2xl | 48px | First-run empty-state vertical padding |
| 3xl | 64px | Reserved — page-level top/bottom breathing room on large viewports |

**Exceptions:**
- `1px` hairline borders (card, column divider, sidebar edge) — standard sub-grid border width, matches DESIGN.md `border-neutral-200`.
- `2px` left-border urgency indicator on Overdue / Due-soon cards, and `2px` keyboard focus ring — both are decoration/affordance widths, not layout spacing.
- Touch targets for icon-only quick-action buttons are `44px` minimum (`h-11 w-11` hit area, icon stays 16px) — 44 is a multiple of 4, no scale violation; called out because it exceeds the visual size of the icon.

## Typography

Two weights only: **regular 400**, **semibold 600**. Four sizes.

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Display | 28px | 600 | 1.2 | Cockpit page title ("Bucles abiertos") |
| Heading | 20px | 600 | 1.3 | Slide-over panel title ("Nuevo bucle" / "Editar bucle") |
| Body | 14px | 400 | 1.5 | Slide-over field values, form inputs, empty-state body, `next_action` textarea |
| Label | 12px | 600 | 1.4 | Column headers (uppercase, `tracking-wide` ≈ 0.06em), count strip, form field labels (weight 600), validation messages |

**Derived treatments (no new sizes/weights):**
- Card title: 14px / **600** / 1.4, `neutral-900`, `line-clamp-2`.
- Relative due-date pill: 12px / 400 / 1.4, Geist Mono, `tabular-nums`, colored per urgency (see Color).
- Owner chip: 12px / 400 / 1.4, `neutral-600`, `border-neutral-200`, `px-2 py-0.5` (DESIGN.md tag-chip pattern exactly).
- Section label ("SIN FECHA"): 12px / 600 / uppercase / `tracking-widest` / `neutral-600` (DESIGN.md section-label pattern).

## Color

Palette is the DESIGN.md `neutral-*` scale on `#fafafa` plus the existing `--cta-accent` token from `app/globals.css`.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#fafafa` (`--background`) | Page background, board area, mobile top bar |
| Secondary (30%) | `#ffffff` cards + slide-over panel; `#f5f5f5` (`neutral-100`) sidebar; `#e5e5e5` (`neutral-200`) all hairline borders / column dividers | Cards, sidebar, nav, slide-over surface |
| Accent (10%) | `#0f172a` (`--cta-accent`), hover `#1e293b` (`--cta-accent-hover`) | See reserved list below |
| Destructive | `#b91c1c` (red-700) | Destructive actions + the Overdue urgency signal (shared — overdue is an error-like state) |

**Accent `#0f172a` reserved for — exhaustive list:**
1. The primary button background: "Añadir bucle" (header), "Añadir tu primer bucle" (first-run), "Crear bucle" / "Guardar cambios" (slide-over footer).
2. The sidebar brand mark tile ("CP").
3. The active sidebar nav-item background tint (`#0f172a` at low opacity or `neutral-100` fill with `#0f172a` text — implementer's choice, but the accent hue only).
4. Keyboard focus rings (2px).

Accent is **never** used for card borders, chips, urgency signalling, links-in-body, or decorative fills.

**Functional status colors** (outside the 60/30/10 decorative budget — urgency signalling is the entire purpose of this cockpit per LOOP-04 / D-01). Applied only as (a) relative-date pill text color and (b) a 2px left card border and (c) the column-header count number. Never as a card background fill.

| Status | Value | Applied to |
|--------|-------|-----------|
| Overdue | `#b91c1c` (red-700) | "Vencidos" column; overdue card left border + date pill ("hace 3 días") |
| Due-soon | `#a16207` (amber-700) | "Vencen pronto" column; card left border + date pill ("vence en 5 días") — the single *additional* semantic hue beyond accent/destructive |
| Waiting-on-others | `#525252` (`neutral-600`) | "A la espera de otros" column — neutral treatment, no colored border |
| No date set | `#737373` (`neutral-500`) | "Sin fecha" collapsed section — muted, never urgent (D-05) |

Contrast: all text colors are `neutral-600` or darker on `#fafafa`/`#ffffff` (DESIGN.md contrast rule). `#b91c1c` and `#a16207` both pass WCAG AA for text on white and on `#fafafa`.

Footer pinned to bottom: `Cancelar` (secondary) + `Crear bucle` / `Guardar cambios` (accent).

| Element | Copy |
|---------|------|
| Slide-over title — create | `Nuevo bucle` |
| Slide-over title — edit | `Editar bucle` |
| Field label — title | `Título` |
| Field label — kind | `Tipo` |
| Field label — next action | `Próxima acción` |

| Field label — owner detail | `Detalle del responsable` |
| Field label — status | `Estado` |
| Field label — due | `Fecha objetivo` |

### Due-date input mechanics (Claude's discretion — resolved)

Native `<input type="date">` (mobile-friendly, zero-dependency; `date-fns` ^4 available for parsing/formatting) preceded by three preset chips: `En 1 semana` · `En 2 semanas` · `En 1 mes`, plus a `Sin fecha` clear control. Rationale: D-specifics list "in 5 days"-style soft deadlines; presets cover the common case, the native picker covers the rest, and native input needs no new dependency or a11y work.

### Destructive action (D-10 `dropped` status; discretion — resolved)

There is **no hard delete** in Phase 1. "Descartar" sets `status = dropped`, which hides the loop from the board (D-07).

| Element | Copy |
|---------|------|
| Destructive control (slide-over, edit mode only) | `Descartar bucle` (text button, destructive color, bottom-left of footer) |
| Inline confirmation (not a modal — appears in place) | `¿Descartar este bucle? Dejará de aparecer en el panel.` |
| Confirm / cancel | `Descartar` (destructive) · `Cancelar` |

## UI Considerations

Applicable state considerations resolved: **11 covered, 1 backstop, 0 unresolved**

| Category | Element(s) | Status | Resolution / Reason |
|----------|------------|--------|---------------------|
| empty | board (list-collection) | ✅ covered | Zero loops renders the first-run state: "Aún no hay bucles abiertos" heading + body + "Añadir tu primer bucle" accent button (see Copywriting Contract → Empty / first-run) (D-18) |
| empty | single column (list-collection) | ✅ covered | A populated board with one empty bucket shows the documented per-column reassurance copy ("Nada vencido" / "Nada vence en los próximos 14 días" / "No estás esperando a nadie") |
| loading | board first paint (list-collection) | ✅ covered | Board is a Server Component reading the store directly (CONVENTIONS storage pattern) — no client fetch, no skeleton needed on first paint |
| loading | quick-action mutation (single-item) | ✅ covered | Only the affected card enters a disabled/pending state (reduced opacity + spinner on the tapped action); the rest of the board stays interactive |
| error | create / edit / quick-action save (mutation) | ✅ covered | Documented copy "No se ha podido guardar el bucle…"; card/panel reverts to prior state; message shown inline (slide-over) or as a transient card-level notice (quick action) |
| error | initial board load (store read) | 🧪 backstop | `lib/cv/*-store.ts` helpers swallow read errors and return `[]` (CONVENTIONS "never throw on read"). A real Blob outage therefore renders as an empty board, not an error screen. Verify this degradation is acceptable for the cockpit, or add an explicit read-failure signal. |
| populated | loop card | ✅ covered | Card shows exactly title + relative due-date pill + owner chip (D-16); `next_action` and `kind` only in the slide-over |
| partial | loop with no `due` date | ✅ covered | Renders in the "Sin fecha" collapsed section (D-05/D-13) with no date pill; ordered by `updated_at` desc (D-06) |
| overflow | long loop title | ✅ covered | Card title `line-clamp-2`; full title visible in the slide-over |
| overflow | many loops in one column | ✅ covered | Column body is `overflow-y-auto` with a bounded `max-h`; column header + count stay pinned |
| overflow | long `owner_detail` | ✅ covered | Owner chip truncates with ellipsis at `max-w-[12ch]`; full value in the slide-over |
| zero-one-many | count strip + column counts | ✅ covered | Spanish singular/plural handled: `1 vencido` vs `{n} vencidos` etc. (see Copywriting Contract → Board furniture) |
| responsive/mobile | board (< `md`) | ✅ covered | Columns stack vertically in priority order Vencidos → Vencen pronto → A la espera → Sin fecha (D-15); quick actions always visible (not hover-gated) at 44px touch targets; slide-over becomes near-full-width |

**Note for planner (not UI):** CONTEXT.md "Claude's Discretion" asks whether LPH-aware `OpenLoop` fields are declared now or in Phase 3. Recommendation: declare them **optional/nullable** on the `OpenLoop` interface now (all `?:`) so Phase 3 adds behaviour, not shape — no UI impact in Phase 1 (those fields are not rendered).

## Interaction & Layout Contract

Prescriptive notes the executor must follow (beyond tokens above):

- **Surface shell:** `app/community-president/layout.tsx` mirrors `app/cv/layout.tsx` — async Server Component, `await cookies()`, `cookie.value !== process.env.DASHBOARD_TOKEN` → `redirect("/dashboard/login")`. Layout renders its own sidebar + `<main>`.
- **Sidebar:** own component (peer of `app/components/dashboard/Sidebar.tsx` but on the `neutral-*` palette). Desktop width `240px` (`w-60`), `bg-neutral-100`, `border-r border-neutral-200`, `fixed` left. `<main>` offset by the same width. Brand: `#0f172a` rounded tile "CP" + `Presidente` / `Comunidad` labels. Nav (Phase 1): a single item `Panel` → `/community-president`. Footer: `Volver al portfolio` (→ `/`) and `Cerrar sesión` (→ `DELETE /api/auth`, then `/dashboard/login`). Keep it minimal — future surfaces add entries as they land (CONTEXT deferred).
- **Mobile (< `md`):** sidebar collapses to a top bar (`#fafafa`, `border-b border-neutral-200`) with a hamburger opening a left sheet drawer (DESIGN.md mobile pattern). Board below it.
- **Board:** CSS grid — `lg:grid-cols-3 gap-4`, `md:grid-cols-1`, single column `< md`. Column order left→right / top→bottom: Vencidos, Vencen pronto, A la espera de otros. "Sin fecha" is a full-width collapsed `<details>`-style section beneath the grid (D-13), default collapsed, showing its count in the summary.
- **Column:** `bg-transparent`, header row = Label-style title + status-colored count. Body = `flex flex-col gap-2`, `overflow-y-auto`, bounded height on desktop so all three columns align.
- **Card:** `bg-white border border-neutral-200 rounded-lg p-4`, `hover:border-neutral-300`, `2px` left border in the urgency color for Vencidos/Vencen pronto. Layout: title (full width, `line-clamp-2`) → row of [relative-date pill] + [owner chip]. Quick-action buttons: 3 lucide icon buttons (`Check`, `Clock`/`PauseCircle`, `CalendarClock`), revealed on `hover`/`focus-within` on desktop, always visible on mobile, `44px` hit area, `neutral-500` → `neutral-900` on hover. Clicking the card body (not a button) opens the edit slide-over.
- **Slide-over (D-08):** `fixed` right, `w-[420px]` desktop / `w-[calc(100vw-32px)]` mobile, `bg-white`, `border-l border-neutral-200`, `shadow-xl`. Enters via `transform: translateX(100%) → 0`, 200ms ease-out (framer-motion; disabled under `prefers-reduced-motion`). Backdrop `rgba(10,10,10,0.2)` over the board; **board stays rendered and visible behind** (D-08) but inert. Dismiss: `Esc`, the `X` in the header, or a backdrop click. Header: Heading-style title + `X` button. Footer: pinned, `Cancelar` (secondary — DESIGN.md secondary CTA) + accent primary; `Descartar bucle` text button bottom-left in edit mode.
- **Count strip:** directly under the page title, `mb-8` (32px) before the board, Label style, `neutral-600` text with status-colored numerals (Geist Mono, `tabular-nums`).
- **Focus / a11y:** every interactive element has a visible `2px` focus ring in the accent hue. Slide-over traps focus while open and restores it to the trigger on close. Quick-action buttons have Spanish `aria-label`s (see Copywriting Contract).
- **Motion:** board columns fade/rise in on mount via the shared `FadeUp` wrapper. No other motion.
